# Code of Conduct

Help make this a useful, respectful place to report problems and improve software.

- Discuss ideas and code without attacking people.
- Make room for different experience levels and communication styles.
- Be specific, patient, and constructive when giving feedback.
- Respect privacy. Do not post another person's private information without permission.
- Do not harass, threaten, discriminate, impersonate others, or deliberately disrupt discussion.

These expectations apply to project issues, pull requests, and other project spaces. The maintainer may edit or remove harmful content, close disruptive discussions, or restrict participation to protect the community.

For concerns, contact the maintainer through a contact route they publish on [Huzaifa Asif's GitHub profile](https://github.com/Huzaifa-Asif). If no suitable private route is available, request one without posting sensitive details. There is no promised response time. Immediate safety concerns should be handled through appropriate local support or platform reporting tools.

This is an original, short policy for this project.
